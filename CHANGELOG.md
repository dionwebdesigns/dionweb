# Changelog

## 1.0.0 (2026-11-14)

- Lintel 1.0.0: classic theme for engineering and construction firms.
- Commons 1.0.0: block theme for non-profits and community organisations.
- Groundwork 1.0.0: projects, services and testimonials, three blocks, an editor panel and a contact form.
- Demo content script for both themes, and a wp-env setup.
- CI for PHP syntax, WordPress Coding Standards, and JavaScript and CSS linting.
